# xsim.dev

Marketing and lead-generation site for xSim, simulation-based executive development. English and Hebrew, hosted free on Cloudflare.

- `PROJECT_CONTEXT.md`: decisions, house style, open items. Start here.
- `DEPLOY.md`: one-time setup and how to publish changes.

```powershell
npm install
npm run dev      # local preview at http://127.0.0.1:8787
npm run deploy   # build and publish
npm run leads    # list the latest briefing requests
```
